배경

다수의 에이전트와 통신하는 신규 보안 솔루션의 서버를 초기 기획 단계부터 맡아 개발하고 있습니다.

맡은 일

초기 기획에 참여하고 DB·백엔드·Gateway를 처음부터 설계·개발했습니다. 초기 React 화면은 프런트엔드 개발자가 담당했고 저는 연동을 지원했습니다. 이후 Alpine.js 관리 화면은 기존 UI 개발자와 협업해 개발했습니다. 현재는 서버와 관리 화면 개발을 함께 맡고 있습니다.

문제와 접근

  • 정책 동기화: 많은 정책과 에이전트 사이의 통신을 가볍게 구성하고 방화벽 제약을 고려하기 위해, 정책을 JSON으로 구성해 SHA-256 해시를 계산하는 방식과 SSE 연결을 적용했습니다. 해시 생성과 정책 변경 알림은 별도 흐름으로 구현했습니다.
  • 인증 처리: Gateway에서 JWT 검증과 인증 실패 응답을 처리하고, 서버가 참조하는 연동 주소를 환경 설정으로 분리했습니다.
  • 관리 기능: 조직 계층을 반영한 자산번호 일괄 부여 기능과, 보안 이력의 검색·조회 조건을 서버 처리와 연결하는 REST API, 보안 통계 집계·Excel 다운로드 기능을 구현했습니다.

검증

Swagger로 API를 호출하거나 직접 테스트하며 동작을 확인하고, 서버의 정상 로그를 확인했습니다. 에이전트와 주고받는 정책 통신은 에이전트 개발자와 함께 점검했고, 오류가 생기면 서버와 에이전트 양쪽 로그를 보며 디버깅했습니다.

배운 점

서버를 처음부터 맡아 설계·개발하며 쌓은 기술과 시행착오가, 이후 개발에서 설계 기준이 되었습니다.

QR 인증 기반 업무 서비스에서 서명과 메일 기능의 서버와 화면을 함께 맡아 2025년 11월부터 12월까지 개발했습니다. 서명 입력·검증과 Canvas 좌표 보정, PDF 생성·전달 및 메일 첨부 기능을 구현했습니다.

성능 테스트

2024년 8~9월 Postman·JMeter로 개인정보보호 제품의 임계치·성능 테스트를 수행하고, 결과는 JMeter 그래프와 Excel로 시각화했습니다. 또한 AWS에 제품을 설치해 환경별 임계치를 테스트했습니다.

고객 현장 기술 지원

기존 솔루션 지원 과정에서 엔지니어가 해결하지 못한 문제를 고객 현장에서 조사·해결했습니다.
