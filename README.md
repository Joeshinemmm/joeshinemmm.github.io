# 조유민 포트폴리오

https://joeshinemmm.github.io/

백엔드 개발자 조유민의 포트폴리오와 이력서 페이지입니다.

| 경로 | 내용 |
|---|---|
| `index.html` | 포트폴리오 |
| `resume.html` | 이력서(브라우저에서 PDF로 저장 가능) |
| `assets/` | 스타일, 스크립트, 사진, 기술 아이콘 |

빌드 과정이 없는 정적 사이트(HTML·CSS·JavaScript)이며 GitHub Pages로 배포합니다.

## 권리 표시

- 사이트 내용과 사진의 권리는 조유민에게 있습니다.
- 기술 아이콘은 [Devicon](https://github.com/devicons/devicon)(MIT 라이선스, `assets/icons/LICENSE-devicon.txt`)에서 가져왔으며, 각 로고의 상표권은 해당 소유자에게 있습니다.
